# Career OS

A personal career management application.

Milestone 1 covers **Goals and Actions only**.

## Stack

- **Frontend:** Angular + TypeScript
- **Backend:** Node.js + TypeScript + Express
- **Database:** SQLite
- **Testing:** Vitest

## Structure

```
/backend    Node.js/Express API
/frontend   Angular app
```

## Milestone 1 Scope

**Goals:** create, list, view, update, delete
**Actions:** add, mark complete, unmark, delete

One goal has many actions.

## Out of Scope for Milestone 1

- Authentication
- Multiple users
- Docker, cloud infrastructure
- GraphQL, microservices

## Conventions

- Always write tests with Vitest
- Keep architecture simple
- No unnecessary dependencies
